# tavya compared

How tavya compares with Claude Code on the web, Codex cloud, Devin, Cursor cloud agents, Paperclip and other ways to run AI agents, checked against each vendor's own documentation in November 2026.

## At a glance

{{comparison}}

A tick means the vendor's documentation describes it. A dash means it does not offer it, or does not document it. A few words mean "in part". Each column links to a page with the details and the sources.

## What is the same everywhere

A cloud computer per task, several agents at once, schedules and event triggers, and a review before work lands are now common. If that is all you need and you already pay for a Claude or ChatGPT plan, the vendor's own cloud agent is the shortest path: it is included in the plan.

## Where tavya is different

- **One list for every vendor's agent.** Claude Code, Codex and any model through OpenCode work in the same projects, and one can review another's work.
- **Agents that can act for you.** A vault of logins they can use without seeing them, saved browser sessions, an inbox of their own, and a card with a budget per task; anything above it waits for your approval.
- **Tasks start tasks.** A task splits into sub-tasks, waits for other tasks, or runs on a schedule or an event. A project can be made fully autonomous, with agents answering and reviewing.
- **Your own cloud account**, on any plan: E2B, Daytona, Fly.io, Hetzner, AWS or Google Cloud.
- **Open source**, under the GNU AGPL-3.0, and [you can host it yourself](/docs/self-hosting).

## Where others are ahead

- **Price for one vendor's users.** Claude Code's and Codex's cloud agents cost nothing beyond the plan; tavya has its own plans ([Pricing](/pricing)).
- **Git hosts.** tavya works with GitHub, or hosts your repositories itself. Devin and Cursor also work with GitLab, Bitbucket and Azure DevOps.
- **Phone apps.** tavya is a web app you can add to your home screen; Claude, ChatGPT and Cursor have native apps.
- **Size.** tavya is a small, new project. The vendors' agents come with their support and their scale.
