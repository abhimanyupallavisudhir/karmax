# Codebase review — 2026-09-26

Scope: all of `karmax` (src, web, tests, deploy, docs), `panagent`, and the project wiki, reviewed against
the 2026-09-08 review ([review-2026-09-08.md](review-2026-09-08.md)) and against karmax's principles
(agents can do everything a human can, one authorization system for both, everything tested end to end).
Method: area reviewers read every module and traced each finding along its real call path; findings that
could not be confirmed were dropped. The console and API were also driven live (fresh install, mock agent).

Severity: CRIT = exploitable across a tenant/trust boundary by an ordinary user or agent, or loses data;
HIGH = the same needing a privileged-but-untrusted actor, or a clear bug on a main path; MED = real but
bounded; LOW = hygiene. Line numbers refer to a5ffe569, the base of this review.

Every finding has a stable ID (`GW-2`, `UI-1`, …). **[fixed <sha>]** marks what this change resolved; the
[Resolution](#resolution) section at the end lists fixes and what remains open.
